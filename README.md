# NH_KOSPI_Model

**AI와 대체데이터를 활용한 KOSPI 예측 모델** 연구 코드입니다. 경제·펀더멘털·텍스트 감성 정보를 결합하고, 강화학습 기반 시장 판단을 탐색한 2021년 연구를 담고 있습니다.


## 연구 결과

2021년 강화학습 코스피 보고서의 백테스트 기간은 **2014-03-14 -- 2021-10-15**입니다. 표 14의 성과는 다음과 같습니다.

| 지표 | KOSPI 예측 모형 | KOSPI |
|---|---:|---:|
| 연율화 수익률 | 12.10% | 6.09% |
| Sharpe | 0.74 | 0.37 |
| MDD | −27.42% | −39.17% |
| 연간 변동성 | 16.32% | 16.44% |

보고서의 Sharpe는 연간수익률/연간변동성으로 정의돼 있어 무위험수익률을 차감하는 정의와 구분해야 합니다. 전체 기간에서는 수익률·낙폭이 개선됐지만, 2019년에는 예측률이 40%로 낮아져 KOSPI보다 성과가 저조했습니다.

감성정보 제외 비교도 제시되지만 표 17의 비교 열 이름과 값에는 확인이 필요한 부분이 있어 여기서는 표 14의 모형·BM 값을 기준으로 소개합니다. 현재 코드의 재학습 성과나 최근 시장 국면의 검증 결과는 아닙니다.

출처: [211019_강화학습_코스피모델.pdf](https://github.com/kyoujinkim/NH_KOSPI_Model/blob/main/211019_%EA%B0%95%ED%99%94%ED%95%99%EC%8A%B5_%EC%BD%94%EC%8A%A4%ED%94%BC%EB%AA%A8%EB%8D%B8.pdf) — PDF 42, 45쪽 — 표 14 및 연도별 성과, 감성정보 제외 비교 45쪽.

## 연구 구성

```text
경제·펀더멘털·텍스트 자료
  → 감성 점수와 수치 특징
  → 상태·행동·보상 구성
  → REINFORCE 학습
  → 투자 판단·성과 비교
```

`SentimentExtractor.py`는 NLTK의 토큰·품사·WordNet·SentiWordNet과 NRC 감성사전 등을 활용한 감성 특징을 다룹니다. `REINFORCE.py`는 TensorFlow 기반 학습 실험을 담고 있습니다. 정책이 학습하는 보상과 실제 비용 차감 수익률은 별도로 확인해야 합니다.

## 기존 연구 결과

기존 문서는 조정 KOSPI를 포함한 총 38개 입력변수(경제 19개·펀더멘털 8개·감성 10개와 조정 지수)를 설명합니다. 당시 코스피 대비 연평균 초과수익률 6%p, 샤프 지수 0.37 개선, 최대낙폭 11.8%p 개선을 보고했고, 감성정보를 제외한 모형과도 비교했습니다.

이는 **2021년 연구의 평가 설정에 따른 기록**입니다. 현재 데이터로 재검증한 수치나 향후 성과를 의미하지 않습니다. 원 보고서 `211019_강화학습_코스피모델.pdf`와 [이전 README](README.previous.md)에 연구 배경을 보존했습니다.

## 환경·입력 준비

루트에 의존성 파일이 없으므로 TensorFlow, NumPy, pandas, scikit-learn, tqdm, NLTK 등 직접 사용 패키지의 호환 환경을 별도로 준비해야 합니다. 이전 TensorFlow 코드와 직렬화된 연구 입력은 최신 환경과 호환되지 않을 수 있습니다.

감성 분석에는 NRC 사전 파일과 NLTK 말뭉치가 추가로 필요합니다. 생성자에 전달하는 사전 경로·점수 계산 방식을 확인하세요. 금융·학습 데이터 경로와 기간·보상·난수 설정은 각 스크립트에서 지정합니다.

## 실행 형태

입력·패키지·경로를 준비한 뒤 저장소 루트에서 실행합니다.

```bash
python REINFORCE.py
```

감성 추출은 별도 클래스 `SentimentExtractor`를 사용합니다. 모듈을 실행하는 것만으로 모든 원문 데이터가 수집·분석되는 구조는 아닙니다.
